## 👩‍💻 About Me

I'm a third-semester **BS Cyber Security** student at **FAST National University (FAST-NUCES), Islamabad**. I'm drawn to how systems break just as much as how they're built — network security, ethical hacking, and vulnerability hunting are what pulled me into this field in the first place.

Outside of coursework, I like turning ideas into working software: wiring up an AI-powered RAG pipeline, designing a website in Figma before writing a line of code, or dry-running C++ until it finally clicks. ## 🚀 Projects

### 🍀 Clover AI
An AI-powered document assistant built with Retrieval-Augmented Generation (RAG) — upload a document, ask questions about it, and get answers grounded in the actual content.

`Python` `Streamlit` `Supabase` `ChromaDB` `Groq API` `BGE Embeddings` `Llama 3.2`

- Semantic search over uploaded documents
- Context-grounded AI question answering, not guesswork
- Clean, simple Streamlit interface

**→ [Live Demo](https://cloverai.streamlit.app/)**

---

### 🌸 The Wandering Bloom
A responsive flower boutique website — designed end-to-end in Figma, then built out with HTML and CSS.

`Figma` `HTML` `CSS`

- Full design pass in Figma before any code
- Clean, uncluttered layout across multiple pages
- Simple, intuitive navigation

**→ [Live Demo](https://25i-6514.github.io/the-wandering-bloom/)**
