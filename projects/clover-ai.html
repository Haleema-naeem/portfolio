Clover AI

A document-based AI assistant built with Retrieval-Augmented Generation — upload a document, ask it anything, and get answers grounded in the actual content.

Try the live demo ↗ GitHub profile

Overview

Clover AI is a document-based AI assistant that lets users upload their own files and ask questions based on what's actually inside them. Instead of guessing from general knowledge, it retrieves the most relevant pieces of the document first, then generates an answer grounded in that content — the core idea behind Retrieval-Augmented Generation (RAG).

The interface is built for simplicity: drop in a document, ask a question in plain English, and get a response that's traceable back to the source material rather than a hallucinated guess.

How it works

  • User uploads a document through the Streamlit interface.
  • The document is chunked and converted into vector embeddings using BGE embeddings.
  • Embeddings are stored and indexed in ChromaDB for fast similarity search.
  • On a question, the most relevant chunks are retrieved from the vector store.
  • Those chunks are passed to Llama 3.2 via the Groq API to generate a grounded answer.
  • Supabase handles backend data persistence behind the scenes.

What I built

I developed the backend retrieval pipeline, the document processing and chunking logic, the connection to the Groq API for generation, and the user-facing Streamlit interface — tying all of it together into a single working assistant a person can actually upload a file to and chat with.
