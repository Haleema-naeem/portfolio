Coding Contest

A C++ coding challenge system — sign up, join contests, and solve programming problems across five difficulty levels.

GitHub profile

Overview

Coding Contest is a C++ system that mimics how online judges and competitive programming platforms work under the hood. Users can sign up, join a contest, and work through programming challenges spread across five difficulty levels.

The focus was on the underlying structure — managing users, contests, and challenges as clean, object-oriented components rather than one tangled script.

What I built

  • User sign-up and account handling.
  • Contest creation and joining logic.
  • Challenge management across five distinct difficulty levels.
  • Core systems written in C++ using object-oriented design.
