The Wandering Bloom

A bouquet shop website, designed from scratch in Figma and built out with HTML & CSS — clean layout, easy navigation, no clutter.

Visit live site ↗ GitHub profile

Overview

The Wandering Bloom is a simple bouquet website built around a warm, plant-shop feel. I started by laying out the whole design in Figma first — thinking through layout, spacing, and how someone would actually move through a flower shop's site — before writing a single line of code.

Once the design felt right, I built it out with HTML and CSS across multiple pages, keeping the navigation simple and the visuals clean so the flowers themselves stay the focus.

What I focused on

  • Full design pass in Figma before any code — layout, hierarchy, spacing.
  • Multiple pages with consistent navigation across the site.
  • A clean, uncluttered visual style that lets the product photography lead.
  • Straightforward, user-friendly browsing — nothing hidden behind extra clicks.
