👾 TumblePop

Overview

TumblePop is a group project developed in C++ using Object-Oriented Programming principles. It recreates the classic arcade game where enemies are sucked into the player's weapon and launched to defeat other enemies. The project demonstrates game logic, collision detection, inheritance, menus and dynamic gameplay.


Main Features

  • Main Menu
  • Player Movement
  • Enemy AI
  • Suction Weapon
  • Scoring System
  • Multiple Levels
  • Collision Detection
  • Game Over Screen

Technologies

C++
Object-Oriented Programming
