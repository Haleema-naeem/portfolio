Tumblepop

A 2D arcade-style game built in C++ for a university project — main menu, scoreboard, enemy variety, and a weapon that pulls enemies in.

GitHub profile

Overview

Tumblepop is a simple 2D game I developed in C++ as a university project. It's built around classic arcade mechanics: players move through levels, deal with a cast of different enemy types, and rack up points on a scoreboard, all wrapped in a main menu that ties the whole experience together.

The core challenge was less about graphics and more about logic — getting player movement, enemy behaviour, and a weapon that can pull enemies inside it to all work together cleanly in code.

What I built

  • A main menu system to start, navigate, and exit the game.
  • A scoreboard that tracks and displays player performance.
  • Multiple distinct player and enemy types with their own behaviour.
  • A weapon mechanic that can pull enemies inside it.
  • Core game logic and player movement written from scratch in C++.
