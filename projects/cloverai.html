🍀 Clover AI

Overview

Clover AI is an intelligent document assistant built using Retrieval-Augmented Generation (RAG). Users can upload PDF documents and ask questions in natural language. Instead of answering from general knowledge alone, the chatbot searches through the uploaded documents using semantic search and generates accurate, context-aware responses. The application features a clean Streamlit interface and runs using local AI models with Ollama, making it fast, private and easy to use.


Features

  • Upload PDF Documents
  • Semantic Search with ChromaDB
  • RAG-based Question Answering
  • Hugging Face Embeddings
  • Local Llama 3.2 Model using Ollama
  • Modern Streamlit Interface
  • Fast Context Retrieval
  • Accurate AI Responses
